# Modelado de Base de Datos en 3FN — UIFCE (FCE - UNAL)

El modelo está normalizado en **Tercera Forma Normal (3FN)**: cada tabla tiene clave primaria (`BIGSERIAL` o `SMALLSERIAL`), atributos atómicos, dependencias funcionales completas respecto a su PK y ausencia de dependencias transitivas.

## Tablas y Restricciones

1. **`roles`**: `id` (`BIGSERIAL PK`), `nombre` (`VARCHAR(50) UNIQUE`: `'solicitante'`, `'tecnico_uifce'`, `'admin_uifce'`), `descripcion` (`VARCHAR(255)`), `created_at`, `updated_at`[cite: 1].
2. **`permisos`**: `id` (`BIGSERIAL PK`), `clave` (`VARCHAR(100) UNIQUE`), `descripcion` (`VARCHAR(255)`)[cite: 1].
3. **`rol_permiso`**: `rol_id` (`BIGINT FK -> roles.id`), `permiso_id` (`BIGINT FK -> permisos.id`), `PK (rol_id, permiso_id)`[cite: 1].
4. **`usuarios`**: `id` (`BIGSERIAL PK`), `rol_id` (`BIGINT FK -> roles.id`), `codigo_unal` (`VARCHAR(12) UNIQUE`), `nombre_completo` (`VARCHAR(150)`), `email_institucional` (`VARCHAR(150) UNIQUE`, dominio `@unal.edu.co`), `password_hash` (`VARCHAR(255)`), `vinculacion` (`VARCHAR(30)`: `'estudiante'`, `'docente'`, `'administrativo'`, `'egresado'`), `telefono_extension` (`VARCHAR(10)`), `activo` (`BOOLEAN DEFAULT TRUE`), `created_at`, `updated_at`[cite: 1].
5. **`tipos_solicitud`**: `id` (`SMALLSERIAL PK`), `codigo` (`VARCHAR(30) UNIQUE`: `'soporte'`, `'videoproyector'`, `'evento'`), `nombre` (`VARCHAR(100)`), `sla_horas_objetivo` (`SMALLINT DEFAULT 24`)[cite: 1].
6. **`solicitudes`**: `id` (`BIGSERIAL PK`), `radicado` (`VARCHAR(30) UNIQUE`), `tipo_solicitud_id` (`SMALLINT FK -> tipos_solicitud.id`), `solicitante_id` (`BIGINT FK -> usuarios.id`), `tecnico_asignado_id` (`BIGINT FK -> usuarios.id`), `estado` (`VARCHAR(30)`), `prioridad` (`VARCHAR(20)`), `asunto` (`VARCHAR(180)`), `descripcion` (`TEXT`), `ubicacion` (`VARCHAR(150)`), `created_at`, `updated_at`, `closed_at`[cite: 1].
7. **`equipos`**: `id` (`BIGSERIAL PK`), `placa_unal` (`VARCHAR(30) UNIQUE`, formato `UNAL-FCE-2026-XXXX`), `serial_fabricante` (`VARCHAR(100) UNIQUE`), `categoria` (`VARCHAR(30)`: `'computo'`, `'videoproyector'`, `'periferico'`, `'red'`), `marca` (`VARCHAR(80)`), `modelo` (`VARCHAR(100)`), `ubicacion_actual` (`VARCHAR(150)`), `estado_operativo` (`VARCHAR(30)`), `fecha_adquisicion` (`DATE`), `created_at`, `updated_at`[cite: 1].
8. **`detalle_soporte`**: `solicitud_id` (`BIGINT PK FK -> solicitudes.id`), `equipo_id` (`BIGINT FK -> equipos.id`), `tipo_mantenimiento` (`VARCHAR(20)`: `'preventivo'`, `'correctivo'`), `diagnostico_tecnico` (`TEXT`), `solucion_aplicada` (`TEXT`)[cite: 1].
9. **`reservas_videoproyector`**: `solicitud_id` (`BIGINT PK FK -> solicitudes.id`), `equipo_id` (`BIGINT FK -> equipos.id`), `fecha_inicio` (`TIMESTAMPTZ`), `fecha_fin` (`TIMESTAMPTZ`), `requiere_cable_hdmi` (`BOOLEAN`), `requiere_adaptador` (`BOOLEAN`), `CHECK (fecha_fin > fecha_inicio)`[cite: 1].
10. **`apoyo_eventos`**: `solicitud_id` (`BIGINT PK FK -> solicitudes.id`), `nombre_evento` (`VARCHAR(180)`), `fecha_evento` (`DATE`), `hora_inicio` (`TIME`), `hora_fin` (`TIME`), `aforo_estimado` (`INTEGER`), `requerimientos_audio_video` (`TEXT`), `CHECK (hora_fin > hora_inicio)`[cite: 1].
11. **`historial_mantenimientos`**: `id` (`BIGSERIAL PK`), `equipo_id` (`BIGINT FK -> equipos.id`), `solicitud_id` (`BIGINT FK -> solicitudes.id`), `realizado_por_usuario_id` (`BIGINT FK -> usuarios.id`), `tipo_mantenimiento` (`VARCHAR(20)`), `fecha_intervencion` (`TIMESTAMPTZ`), `descripcion_trabajo` (`TEXT`), `observaciones` (`TEXT`)[cite: 1].
12. **`auditoria_eventos`**: `id` (`BIGSERIAL PK`), `usuario_id` (`BIGINT FK -> usuarios.id`), `entidad` (`VARCHAR(60)`), `entidad_id` (`VARCHAR(60)`), `accion` (`VARCHAR(60)`), `estado_anterior` (`VARCHAR(60)`), `estado_nuevo` (`VARCHAR(60)`), `detalle_json` (`JSONB`), `ip_origen` (`INET`), `created_at` (`TIMESTAMPTZ`)[cite: 1].
